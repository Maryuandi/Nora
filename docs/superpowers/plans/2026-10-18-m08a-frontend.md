# M08a Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah tab "Penilaian" yang menampilkan hasil penilaian Jev (tiruan) atas kandidat hipotesis per temuan, antrean review, dan koreksi analis.

**Architecture:** Fungsi murni di `lib/mock/assessment.ts` (skor total, status dari ambang, nilai efektif, antrean), fixture + seed di `assessment-data.ts`, tiga aksi reducer di `assessment-reducer.ts` yang didelegasikan dari `reduce` di `reducer.ts`, lalu dua rute di `projects/[projectId]/assessments/` dengan komponen bersama. Semua data tiruan; tidak ada backend.

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind v4, Untitled UI (react-aria), Phosphor, Zod, Vitest. Tanpa dependensi baru.

**Spec:** `docs/superpowers/specs/2026-10-18-m08-frontend-design.md`

## Global Constraints

- Semua teks UI Bahasa Indonesia. Ikon hanya `@phosphor-icons/react`. Judul halaman 20px, kontrol 32px (`Button size="xs"`, `Input size="sm"`).
- Fungsi di `assessment.ts` dan `assessment-data.ts` murni (tanpa React, tanpa `Date.now()`/acak). Reducer murni, tidak melempar; tiap aksi sukses menambah **tepat satu** `AuditEvent`; pada galat state dikembalikan dengan referensi yang sama. Jam tetap `MOCK_TODAY`.
- Ambang: `THRESHOLDS = { sufficient: 0.5, topProb: 0.6, margin: 0.15 }`. Status: `otomatis`, `perlu_review`, `informasi_tidak_cukup`, `gagal`, `tertunda`. Relevansi: `relevan`, `sebagian_relevan`, `tidak_relevan`, `informasi_tidak_cukup`.
- Skor total = `Σ (level−1)/4 × bobot × 100`, satu desimal, dihitung kode, tidak pernah oleh model.
- Izin: `assessment.view` semua peran; `assessment.run` dan `assessment.correct` hanya `analis`. Aksi tulis hanya saat proyek `aktif` (`acceptsData`). Audit: `penilaian.jalankan`, `penilaian.koreksi`, `penilaian.konfirmasi`.
- Hasil model (`Assessment`) tidak pernah diubah oleh koreksi. Label "Dinilai model" tampil sampai ada koreksi atau konfirmasi.
- Semua string data dirender sebagai teks (tanpa `dangerouslySetInnerHTML`); nilai panjang terpotong dengan `title`. Hooks sebelum early return. Status bukan hanya warna (selalu ada teks); bilah probabilitas selalu punya angka.
- Jangan sentuh backend, branch lain, atau berkas di luar `apps/web` dan `docs/`. Tidak ada berkas sementara tersisa.
- Commit tanpa baris Co-Authored-By Claude (preferensi pengguna).

## Perubahan atas spec (diputuskan di plan, perbarui spec di Task 1)

- `Assessment` mendapat `supersededBy?: string` (id hasil yang menggantikannya). Semua tampilan memakai hasil yang `supersededBy` kosong.
- Aksi `assessment/run` membawa `scope: "belum_dinilai" | "semua"`.
- Seed temuan kedua sengaja **tanpa** hasil untuk kandidat ketiga (`c9`) agar tombol "Jalankan penilaian" punya pekerjaan di demo.

## Review Focus

- Probabilitas persis di batas (0,5 / 0,6 / selisih 0,15): `informasi_tidak_cukup` hanya bila `< 0,5`; `perlu_review` hanya bila teratas `< 0,6` atau selisih `< 0,15`; nilai tepat batas → lolos ke status berikutnya.
- Dua opsi teratas seri: margin 0 → `perlu_review`; argmax deterministik (urutan opsi tetap).
- Kriteria tanpa skor atau bobot tidak berjumlah 1: total dinormalisasi; tanpa skor sama sekali → `null` dan UI menampilkan "–", bukan `NaN`.
- Koreksi ganda pada hasil yang sama: koreksi terbaru menang, yang lama tetap ada; menjalankan ulang tidak menghapus koreksi.
- Alasan koreksi hanya spasi atau 501 karakter: ditolak dengan pesan.
- Peran pemilik_proses/administrator atau proyek tidak aktif mencoba menjalankan/mengoreksi: ditolak, state sama, tombol tersembunyi.
- Nama kandidat/alasan berisi `<script>` atau 5000 karakter tanpa spasi: tampil sebagai teks, terpotong, tata letak utuh.
