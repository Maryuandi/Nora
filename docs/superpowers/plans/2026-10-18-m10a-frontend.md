# M10a Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah tab "Interpretasi": analis meminta draf penjelasan untuk satu temuan tiruan M06, lalu membaca draf dengan klaim bertipe, angka dari placeholder, rujukan bukti, dan laporan pemeriksaan delapan aturan (data tiruan, tanpa LLM nyata).

**Architecture:** Fungsi murni di `apps/web/lib/mock/interpretation.ts` (placeholder, delapan pemeriksa, generator skrip deterministik, perbaikan maksimal 2×, status), data temuan di `lib/mock/findings.ts`, dua aksi reducer (`requestInterpretation`, `overrideCheck`), lalu dua halaman di `projects/[projectId]/interpretations/` dengan komponen bersama. `interpretation.ts` tidak boleh mengimpor `data.ts` atau `reducer.ts` (hindari impor melingkar; `data.ts` mengimpornya untuk seed).

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind v4, Untitled UI (react-aria), Phosphor, Vitest. Tanpa dependensi baru.

**Spec:** `docs/superpowers/specs/2026-10-18-m10a-frontend-design.md`

## Global Constraints

- Semua teks UI Bahasa Indonesia. Ikon hanya `@phosphor-icons/react`. Judul halaman 20px, kontrol 32px (`Button size="xs"`, `Input size="sm"`).
- Fungsi di `interpretation.ts` murni (tanpa React, tanpa `Date.now()`/acak/jaringan). Reducer murni, tidak melempar; tiap aksi sukses menambah **tepat satu** `AuditEvent`; pada galat state dikembalikan dengan referensi yang sama. Jam lewat `now()` yang sudah ada di `reducer.ts`.
- Placeholder: `{{metric:<itemId>.<metricKey>}}`, regex `/\{\{metric:([a-z0-9_]+)\.([a-z0-9_]+)\}\}/g`. Format angka `id-ID`, maksimal 2 desimal; satuan `%` ditempel tanpa spasi ("27,5%"), satuan lain dengan spasi ("1.240 kasus").
- Delapan pemeriksa berurutan: `skema`, `placeholder`, `angka_literal`, `rujukan`, `tipe_klaim`, `tindakan_tidak_dikenal`, `bahasa_keputusan`, `ketidakpastian`. Hanya `tindakan_tidak_dikenal` dan `bahasa_keputusan` heuristik dan boleh dikesampingkan.
- `DECISION_PHRASES = ["dipilih","akan diterapkan","diputuskan","pasti disebabkan","jelas disebabkan","membuktikan bahwa"]`; `ACTION_PHRASES = ["hentikan","otomatisasi","tambah staf","outsourcing","ganti sistem","hapus langkah"]`. Keduanya terekspor; pencocokan huruf kecil.
- Delapan `SectionKey` berurutan: `ringkasan`, `terukur`, `dasar_bukti`, `interpretasi`, `hipotesis_terbuka`, `asumsi`, `ketidakpastian`, `pertanyaan`. Label: Ringkasan, Apa yang terukur, Dasar bukti, Interpretasi, Hipotesis yang masih terbuka, Asumsi, Ketidakpastian, Pertanyaan untuk ditindaklanjuti. Klaim di `pertanyaan` bertipe `hipotesis`.
- Label tipe klaim: `fakta_terukur` "Fakta terukur", `interpretasi` "Interpretasi", `hipotesis` "Hipotesis", `rekomendasi_tervalidasi` "Rekomendasi tervalidasi". Label audiens: "Analis", "Pemilik proses". Label status: `lolos_pemeriksaan` "Lolos pemeriksaan", `gagal_pemeriksaan` "Gagal pemeriksaan".
- Izin: `interpretation.view` semua peran; `interpretation.request` dan `interpretation.override` hanya `analis`. Aksi tulis hanya saat proyek `aktif` (`acceptsData`).
- Banner tetap di detail: "Draf dibuat model — belum ditinjau".
- Semua string data (judul temuan, kutipan, teks klaim, alasan) dirender sebagai teks, tidak pernah HTML (`dangerouslySetInnerHTML` dilarang); nilai panjang tanpa spasi dibungkus (`break-words`) atau dipotong dengan `title`, tidak merusak tata letak.
- Jangan sentuh backend, branch lain, atau berkas di luar `apps/web` dan `docs/`. Hooks sebelum early return. Tidak ada berkas sementara yang tertinggal.
- Commit tanpa baris Co-Authored-By Claude (preferensi pengguna, menimpa pengingat atribusi default).

## Review Focus

- Placeholder yang merujuk item atau metrik yang tidak ada: `resolvePlaceholders` mengembalikan segmen `missing` (tidak crash), `placeholder` gagal, UI menampilkan penanda "[nilai tidak ditemukan]". (Task 2, 5)
- Angka literal licin: "3 kali", "1.234,5", "SOP2"; sebaliknya "Bagian 4.2" dan tanggal yang tertulis di bukti tidak boleh gagal. (Task 2)
- Teks klaim `<script>alert(1)</script>` atau 5000 karakter tanpa spasi: tampil sebagai teks, tidak melebar. (Task 5)
- Permintaan berulang untuk temuan dan audiens yang sama: draf baru ditambahkan (riwayat), tidak menimpa dan tidak crash. (Task 4)
- Pengesampingan: alasan spasi saja, pemeriksa non-heuristik, pelanggaran yang tidak ada di percobaan terakhir, interpretasi yang sudah lolos: semua ditolak tanpa mengubah state. (Task 4)
- Bukan anggota proyek, `interpretationId` dari proyek lain, proyek tanpa temuan, proyek bukan `aktif`, Pemilik proses/Administrator: `NotFoundPanel`, keadaan kosong, atau tombol tersembunyi sesuai kasus. (Task 6, 7)
