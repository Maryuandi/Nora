# M04c Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah tab "Konteks" dengan layar Aturan terstruktur M04c (daftar, formulir + pratinjau, detail + alur status) berdata tiruan di atas M03a.

**Architecture:** Fungsi murni baru di `apps/web/lib/mock/rules.ts` (label kanonis, validasi, pratinjau, transisi), lima aksi reducer (`saveRule`, `changeRuleStatus`, `confirmRuleClient`), lalu tiga halaman di bawah `projects/[projectId]/context/rules/` dengan komponen bersama. Semua turunan dihitung di klien dari snapshot dan pemetaan tiruan; tidak ada backend.

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind v4, Untitled UI (react-aria), Phosphor, Vitest. Tanpa dependensi baru.

**Spec:** `docs/superpowers/specs/2026-10-17-m04c-frontend-design.md`

## Global Constraints

- Semua teks UI Bahasa Indonesia. Ikon hanya `@phosphor-icons/react`. Judul halaman 20px, kontrol 32px (`Button size="xs"`, `Input size="sm"`).
- Fungsi di `rules.ts` murni (tanpa React, tanpa `Date.now()`/acak, tanpa dependensi baru). Reducer murni, tidak melempar; tiap aksi sukses menambah **tepat satu** `AuditEvent`; pada galat state dikembalikan dengan referensi yang sama. Jam tetap `MOCK_TODAY`.
- Jenis aturan: `sla`, `urutan`, `wajib`, `terlarang`, `pemisahan_tugas`. Status: `draf`, `ditinjau`, `disetujui`, `usang`. Transisi: `draf→ditinjau`, `ditinjau→draf|disetujui`, `disetujui→usang`.
- Izin: `rule.edit` hanya `analis`; `rule.confirm` hanya `pemilik_proses`; `rule.view` semua peran. Semua aksi tulis hanya saat proyek `aktif` (`acceptsData`).
- Setujui ditolak bila rujukan sumber (`docTitle`, `section`, `quote`) ada yang kosong ("Aturan tanpa rujukan sumber tidak dapat disetujui") atau pratinjau `tidak_dapat_dievaluasi` ("Aturan tidak dapat dievaluasi: {alasan}").
- Semua string data (nama, kutipan, label) dirender sebagai teks, tidak pernah HTML (`dangerouslySetInnerHTML` dilarang); nilai panjang terpotong dengan `title` dan tidak merusak tata letak.
- Jangan sentuh backend, branch lain, atau berkas di luar `apps/web` dan `docs/`. Hooks sebelum early return. Tidak ada berkas sementara yang tertinggal.
- Commit tanpa baris Co-Authored-By Claude (preferensi pengguna).

## Review Focus

- Aktivitas sama untuk dua peran yang harus berbeda (SLA from=to, urutan before=after, pemisahan A=B): ditolak per bidang.
- SLA `limit` 0, negatif, kosong, `NaN`, atau sangat besar (mis. 1e9): ditolak atau dijaga tanpa crash di pratinjau.
- `effectiveTo` sebelum `effectiveFrom` dan tanggal tak valid: ditolak.
- Mengedit aturan `disetujui`: versi baru `draf` dibuat, versi lama tetap `disetujui` sampai versi baru disetujui, lalu menjadi `usang`; konfirmasi klien versi baru mulai dari `false`.
- Aturan merujuk aktivitas yang sudah tidak ada di label kanonis (pemetaan baru): halaman detail menampilkan peringatan, tidak crash; menyimpan ulang ditolak sampai aktivitas diganti.
- Proyek tanpa pemetaan sama sekali: formulir tidak crash, pilihan aktivitas kosong dengan tautan ke Pemetaan, pratinjau "tidak dapat dievaluasi".
- Kutipan atau nama aturan berisi `<script>` atau 5000 karakter tanpa spasi: tampil sebagai teks dan terpotong.
