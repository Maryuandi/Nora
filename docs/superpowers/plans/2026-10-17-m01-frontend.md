# M01 Frontend (Mock Data) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Sembilan layar M01 bergaya Oneleet dengan data tiruan di memori, navigasi lengkap, dan pemilih peran pratinjau.

**Architecture:** Tailwind v4 + token tema di `apps/web/app/globals.css`; komponen dasar di `apps/web/components/ui/`; logika data tiruan murni (reducer + `can()`) di `apps/web/lib/mock/` yang diuji Vitest; `MockStoreProvider` (React context) membungkus grup rute `(app)` yang punya sidebar; grup `(auth)` tanpa sidebar untuk login dan aktivasi.

**Tech Stack:** Next.js 16 App Router (sudah ada), Tailwind CSS v4, `next/font` Inter, `@phosphor-icons/react`, **Untitled UI React** (gratis; React Aria + Tailwind v4; dipasang lewat `npx untitledui@latest add <komponen>`), Zod (sudah ada), Vitest (sudah ada).

**Komponen UI:** semua komponen dasar memakai Untitled UI React di path bawaannya (`@/components/base/...`, `@/components/application/...`), dengan warna brand diset ke `#2F399F`. API Button: `color` `primary | secondary | tertiary | link-color | link-gray | primary-destructive | secondary-destructive | tertiary-destructive`, `size` `xs | sm | md | lg | xl`, `iconLeading`/`iconTrailing` (komponen ikon Phosphor), `isLoading`, `isDisabled`, `href` untuk tautan. Bila suatu komponen tidak tersedia di versi gratis, tulis di atas React Aria memakai token yang sama dan catat di laporan. Di bawah, nama file `components/ui/*` diganti oleh path Untitled UI yang sesuai.

**Spec:** `docs/superpowers/specs/2026-10-17-m01-frontend-design.md`

Semua path relatif ke root repo `nora/`.

## Global Constraints

- Token visual persis dari spec: font Inter, `letter-spacing: -0.01em` global; aksen `#2F399F`, latar pudar aksen `#ECEDF8`; kanvas `#FBFAF9`; sidebar `#F6F5F3`; garis `#E6E4E1`; teks `#1C1B1A` / `#5E5B57` / `#7A7773`; status hijau `#2A9D78`, kuning `#E5A100`, abu `#C8C5C0`, merah `#D8402B`; kartu radius 8px; kontrol tinggi 32px radius 7px.
- Ikon hanya Phosphor (`@phosphor-icons/react`): regular default, `weight="fill"` untuk item aktif. Tidak ada Lucide.
- Copy UI bahasa Indonesia, sentence case, tanpa "silakan"/"berhasil!"; label status: `Draft`, `Aktif`, `Ditangguhkan`, `Berakhir`, `Diarsipkan`; peran: `Administrator`, `Analis`, `Pemilik proses`.
- Tanpa database, auth sungguhan, API baru, atau penyimpanan permanen. Data hilang saat muat ulang.
- Proyek yang tidak ada atau bukan milik pengguna pratinjau → halaman "Tidak ditemukan" (bukan "akses ditolak").
- Desktop: tampil benar di 1280px, tidak rusak di 1024px. Tanpa mode gelap.
- Pemilih peran diberi label "Mode pratinjau".
- Commit tanpa trailer `Co-Authored-By` atau atribusi Claude/AI (preferensi pengguna).

## Review Focus

- Pengguna pratinjau berganti peran saat sedang di halaman proyek yang bukan miliknya → halaman berubah ke "Tidak ditemukan", tidak crash (Task 5).
- Form dikirim dengan spasi saja (`"   "`) di kolom wajib → ditolak dengan pesan per kolom (Task 4, tes skema).
- Daftar proyek dengan nama/klien panjang → teks terpotong elipsis, kartu tidak melebar (Task 3).
- Menambah anggota dengan email yang sudah jadi anggota → peran diperbarui setelah konfirmasi, bukan duplikat (Task 2 tes reducer, Task 5 UI).
- Tanggal kontrak berakhir ≤ 14 hari dihitung dari tanggal "hari ini" tiruan yang tetap (`MOCK_TODAY`), agar tampilan demo konsisten (Task 2).
