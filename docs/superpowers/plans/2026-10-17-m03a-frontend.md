# M03a Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah layar Pemetaan M03a (peran kolom, waktu, label aktivitas, versi pemetaan) dengan data tiruan di atas M02 frontend.

**Architecture:** Fungsi murni baru di `apps/web/lib/mock/mapping.ts` (saran, deteksi, pratinjau, validasi), satu aksi reducer `saveMapping`, lalu dua halaman di bawah `sources/[sourceId]/` yang memakai komponen form bersama. Semua turunan dihitung di klien dari snapshot tiruan; tidak ada backend.

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind v4, Untitled UI (react-aria), Phosphor, Vitest. Tanpa dependensi baru.

**Spec:** `docs/superpowers/specs/2026-10-17-m03a-frontend-design.md`

## Global Constraints

- Semua teks UI Bahasa Indonesia. Ikon hanya `@phosphor-icons/react`. Judul halaman 20px, kontrol 32px (`Button size="xs"`, `Input size="sm"`).
- Fungsi di `mapping.ts` murni (tanpa React, tanpa `Date.now()`/acak, tanpa dependensi baru). Reducer murni, tidak melempar; tiap aksi sukses menambah **tepat satu** `AuditEvent`. Jam tetap `MOCK_TODAY`.
- Peran wajib: `case_id`, `activity`, `timestamp_end`; masing-masing tepat satu kolom. Zona waktu pilihan: `Asia/Jakarta`, `Asia/Makassar`, `Asia/Jayapura`, `UTC`.
- Menyimpan hanya saat proyek `aktif` (`acceptsData`), oleh `administrator` atau `analis`; `pemilik_proses` hanya melihat.
- Nilai contoh dan label dirender sebagai teks, tidak pernah HTML (`dangerouslySetInnerHTML` dilarang).
- Jangan sentuh backend, branch lain, atau berkas di luar `apps/web` dan `docs/`. Hooks sebelum early return.
- Commit tanpa baris Co-Authored-By Claude (preferensi pengguna).

## Review Focus

- Kolom dengan nama sama persis dua kali, atau nama berbeda hanya huruf besar-kecil: peran wajib tetap hanya satu kolom, tidak crash.
- Snapshot tanpa kolom wajib sama sekali (mis. hanya kolom `Amount`): halaman tidak crash, semua galat "Pilih kolom untuk …" tampil, tombol simpan tidak menyimpan.
- Waktu contoh kosong atau tidak cocok format: pratinjau menandai `timeUtc: null`, bukan `Invalid Date` atau galat.
- Label dipetakan melingkar (A→B dan B→A) atau kanonis kosong: ditolak dengan pesan.
- Simpan dua kali berturut-turut tanpa perubahan: kedua kali versi tidak bertambah; setelah perubahan kecil versi naik satu.
- Nama kolom/label sangat panjang atau berisi `<script>`: terpotong/diescape, tidak merusak tata letak.
