# M07 Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tab "Jejak" per proyek: daftar temuan, jejak bukti (graf + daftar), eksplorasi aktivitas, paket bukti, status graph + rebuild, semuanya di atas data tiruan.

**Architecture:** Fungsi murni di `lib/mock/graph.ts` (bangun graf dari `MockState`, lineage, neighborhood, kesegaran) + dua aksi reducer untuk rebuild. Simpul Source/Snapshot/MappingVersion/Rule diturunkan dari state M02-M04c yang sudah ada; sisanya diseed di `lib/mock/graph-data.ts`. UI mengikuti pola halaman M04c (`useProject`, `Card`, `Table`, `Pill`, Phosphor).

**Tech Stack:** Next.js 16 app router, React 19, Tailwind v4 + Untitled UI, Phosphor, vitest, `@xyflow/react` (baru).

**Spec:** `docs/superpowers/specs/2026-10-18-m07-frontend-design.md`. Semua kerja di `/Users/maryuandi/Documents/Lomba/Angel Hackathon/nora/apps/web`, branch `feat/m07-frontend`.

## Global Constraints

- Frontend saja: tanpa Neo4j, outbox, Temporal, backend, penyimpanan permanen.
- Aksi UI di-gate lewat `can()` di `lib/mock/permissions.ts`; aksi tulis hanya pada proyek `aktif` (`acceptsData`).
- `buildGraph` dan semua turunannya selalu menyaring `projectId`; simpul/relasi proyek lain tidak pernah muncul.
- Relasi `dukungan_hipotesis` berlabel "belum terbukti"; halaman graf dan eksplorasi selalu menampilkan banner "Hubungan dalam graph bukan bukti sebab-akibat."
- Batas bawaan eksplorasi 50 simpul per kelompok; ambang basi graph 5 menit.
- Teks UI Bahasa Indonesia. Ikon Phosphor (`@phosphor-icons/react`). Aksen #2F399F lewat token yang sudah ada (`text-accent`, `border-line`, `text-ink-*`).
- Waktu tiruan tetap: `MOCK_TODAY = "2026-10-17"`, `now() = 2026-10-17T09:30:00Z` di reducer.
- Commit tanpa baris Co-Authored-By Claude / "Generated with Claude Code".
- Branch lain (`feat/m05a-frontend`, `feat/m08-frontend`) juga menambah ke `MockState`/`types.ts`/layout proyek; tambahan M07 ditaruh di file baru atau di baris terpisah agar konflik merge kecil.
