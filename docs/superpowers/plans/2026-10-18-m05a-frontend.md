# M05a Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Tambah tab "Analisis" dengan halaman Peta proses M05a (DFG frekuensi/performa, slider penyederhanaan, panel kasus yang konsisten dengan angka peta) berdata tiruan.

**Architecture:** Fungsi murni baru: `lib/mock/eventlog.ts` (event log deterministik, DFG, penyederhanaan, kasus per elemen) dan `lib/mock/layout.ts` (tata letak dagre sekali dari graf lengkap). Komponen klien React Flow menggambar peta; panel kasus membaca indeks yang sama dengan peta sehingga jumlahnya identik. Tidak ada backend.

**Tech Stack:** Next.js 16 App Router, TypeScript, Tailwind v4, Untitled UI, Phosphor, Vitest, `@xyflow/react` dan `@dagrejs/dagre` (dependensi baru, disetujui).

**Spec:** `docs/superpowers/specs/2026-10-18-m05a-frontend-design.md`

## Global Constraints

- Semua teks UI Bahasa Indonesia. Ikon hanya `@phosphor-icons/react`. Judul halaman 20px, kontrol 32px (`Button size="xs"`, `Input size="sm"`).
- Fungsi di `eventlog.ts` dan `layout.ts` murni: tanpa React, tanpa `Date.now()` dan `Math.random()`, deterministik dari `snapshot.checksum` (hash FNV yang sudah ada di `mapping.ts`, diekspor sebagai `hash`).
- Dependensi baru hanya `@xyflow/react` dan `@dagrejs/dagre` (+ tipe bila perlu); tidak ada yang lain. Versi dikunci eksplisit (bukan `latest`), dipilih yang kompatibel dengan React 19.
- Invarian konsistensi wajib lulus untuk seluruh elemen pada log seed: `casesForNode(a).length === node.caseCount`, `casesForEdge(a,b).length === edge.caseCount`, jumlah `edge.count` = jumlah pasangan event berurutan + 2 × jumlah kasus (tepi awal dan akhir).
- Kasus paling banyak 400 (`min(round(rows/6), 400)`). Aktivitas paling banyak 8. Slider 1 sampai 100.
- Semua string dari data (label aktivitas, ID kasus) dirender sebagai teks, tidak pernah HTML; nilai panjang terpotong dengan `title`. Hooks sebelum early return.
- Jangan sentuh backend, branch lain, atau berkas di luar `apps/web` dan `docs/`. Tidak ada berkas sementara yang tertinggal. Commit tanpa baris Co-Authored-By Claude (preferensi pengguna).

## Review Focus

- Persentil (median/P90) pada 1 dan 2 sampel, dan pada jeda 0 ms: tidak NaN, tidak melempar.
- Kasus dengan hanya satu event: tepi `__start → a` dan `a → __end` ada, tidak ada tepi di antaranya; kasus tetap terhitung.
- Aktivitas yang sama berulang berurutan (A→A) dan bolak-balik (A→B dan B→A): tepi terpisah, jumlah benar, tidak digabung.
- Slider 1% pada aktivitas dan transisi: peta tidak kosong tanpa penjelasan, awal/akhir tetap ada, hitungan tersembunyi benar; slider 100% tidak menyembunyikan apa pun.
- Snapshot atau pemetaan yang menghasilkan kurang dari 2 aktivitas, atau tanpa snapshot sama sekali: keadaan kosong dengan tautan, tidak crash.
- Label aktivitas sangat panjang atau berisi `<script>`: terpotong di simpul, tampil sebagai teks di panel dan label tepi.
- Resize jendela dan beralih mode/slider cepat: posisi simpul tidak berubah (layout dihitung sekali); tidak ada render ulang tak berujung.
