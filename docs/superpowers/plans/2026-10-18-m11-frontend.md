# M11 Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bangun M11 (workspace investigasi, catatan, diskusi, tinjauan model, keputusan berjejak, penanda tinjau ulang, usulan ke M04) sebagai frontend dengan data tiruan.

**Architecture:** Tambah tipe, aturan murni (`investigation.ts`), dan aksi reducer ke lapisan tiruan `apps/web/lib/mock/`; aksi investigasi hidup di `investigation-reducer.ts` yang didelegasikan dari `reduce()`; UI di rute `projects/[projectId]/investigations/` memakai komponen Untitled UI dan pola Nora yang sudah ada.

**Tech Stack:** Next.js (App Router), React, TypeScript, Tailwind v4, Untitled UI (React Aria), Phosphor Icons, Vitest. Tidak ada dependensi baru.

**Spec:** `docs/superpowers/specs/2026-10-18-m11-frontend-design.md` (dibaca bersama bagian "Koreksi spec" di bawah).

## Koreksi spec (keputusan plan; menang atas spec bila berbeda)

Ditemukan saat membaca kode M10a; Task 3 dan 8 menerapkannya, dan spec diperbarui di komit yang sama dengan plan ini.

1. Metrik nyata di `findings.ts` adalah `finding_42.p90_days` (18,4 hari kerja), bukan `p90_hari` 9,4. `metricValues` kunci `"finding_42.p90_days"`; analisis baru mengubahnya 18,4 → 22,1. Teks ringkasan: `"P90 berubah dari 18,4 ke 22,1 hari kerja"`.
2. Hasil Jev tidak perlu seed terpisah: `JevResult` diturunkan dari item bukti `kind: "hasil_jev"` (`jev_42`, skor 0,82). Tautan `hasil_jev` menunjuk id item bukti; hapus tipe `JevResult` dan `jevResults` dari `MockState`.
3. Kandidat `cand_1` (tervalidasi) dan `cand_2` (tidak) sudah ada di `finding_42`. Hanya `cand_1` yang bisa `dipilih`/`usulan_uji_coba`.
4. `createProposal` tidak memakai "masukan aturan terbaru tanpa perubahan" (ditolak `saveRule` sebagai "Tidak ada perubahan"). Masukan: `{ projectId; investigationId; ruleKey; note }`; reducer memanggil `saveRule` dengan `description = note` pada masukan aturan terbaru, lalu `changeRuleStatus → ditinjau`. Aturan terakhir yang sudah `draf`/`ditinjau` ditolak ("Sudah ada usulan berjalan").
5. Tidak ada `jevResults`; tidak ada `Notification` untuk penulis sendiri.

## Global Constraints

- Teks UI Bahasa Indonesia; ikon `@phosphor-icons/react`; kontrol 32px; judul halaman 20px; pakai `Pill`, `Card`, `Table`, `NoraModal`, `Banner`, `NotFoundPanel` yang ada.
- Semua string pengguna (judul, isi catatan, komentar, alasan, nama berkas, tautan) dirender sebagai teks, tidak pernah HTML. Tautan bukti: `rel="noreferrer"`, hanya skema `http(s)`.
- Reducer tidak pernah melempar; galat berupa string `error`; aksi sukses menulis tepat satu `AuditEvent`; aksi tulis hanya pada proyek `aktif` (`acceptsData`).
- Bukti berkas ≤ 20 MB (`20 * 1024 * 1024`). Ambang perubahan metrik penanda: 5% relatif.
- Jam tetap `MOCK_TODAY`; id lewat helper `id()`.
- Keputusan, komentar, catatan tidak dapat dihapus.
- Cabang `feat/m11-frontend`, worktree `nora-m11`. Komit tanpa baris Co-Authored-By Claude atau "Generated with Claude Code" (preferensi pengguna).
- Perintah dijalankan dari `apps/web`: `pnpm test` (vitest run), `pnpm build`.

## Review Focus

1. Dua pengguna memutuskan target sama: yang kedua dengan `expectedVersion` basi mendapat galat dan state tidak berubah (Task 7).
2. `siap_diputuskan` terkunci selama ada keluaran model belum ditinjau; terbuka lagi setelah ditinjau; keluaran yang ditautkan belakangan ikut menguncinya (Task 2, 4).
3. Draf interpretasi `gagal_pemeriksaan` tidak dapat disetujui (Task 6).
4. Pemilik proses tidak dapat menetapkan selain `dipilih`; analis tidak dapat `dipilih`; administrator tidak dapat apa pun (Task 1, 7).
5. Sebutan `@nama` ke nama tak dikenal atau penulis sendiri tidak membuat notifikasi; nama berkas > 20 MB dan tautan non-http ditolak (Task 5).
